## 一致性與接受範圍

十段連續合計90分鐘；Greenfield22、Time Skip至Delivery（29–80）Brownfield51，其中B313；Retrospective10。分批發B1／B2／B3，不把完整Evaluation、Reference Solution、Bundle、作者Repository、Git歷史或未來任務答案交給Participant。內部Reference連結只供評估者定位，不構成分發授權；Recovery必須依[受控復原計畫](../../06-runbook/recovery-plan.md)白名單／排除清單與已驗收來源，未有合格包則採分析／Review降級，不直接分享答案目錄。

O-01：本次採90分鐘、個人Greenfield→Time Skip統一B0→獨立Agent分析→Shared Context→主要Agent交付。一日／半日及跨角色交接的contents素材保留作方法參考，不列為本次必做；Context來源與交接方法映射到上述兩段。P10為文件對齊，真實排程／Recovery演練仍待P11，不刪原決策歷史。

O-02：學員功能Level1分析／Level2核心／Level3完整交付與P9 A–E五維治理評分是兩軸，不互代。Level1／2可構成學習成果，但完整軟體交付仍須全部AC／Regression／文件／Review；產製者Reference Solution不因學員時間分級降低DoD。Rubric總15只用回顧，不排名、不用程式量或自主率作唯一標準。

B0不是一般pytest全過：只一個受控Bug，failed node ID集合須精確等於已核實Manifest五項，其餘通過且零非預期、無Skip／XFail；B1全部恢復。G0可有受控Feature Skip；G1及B1–B3完整測試全過。既知Warning可識別，未知失敗不放行。各版本原始報告與本場Preflight結果分開，空勾選不是已執行證據。

完成條件：每階段目的／輸入／成果／AC／提示／內部答案／接受範圍／驗證皆有真實定位；時程、分批與安全Recovery、功能與治理評估界線一致，未編造學員結果；真人活動／切換／閱讀時間仍待演練；目前候選包與技術復原結果見[一致性修正報告](../../06-runbook/evaluation/consistency-correction-report.md)，不以機械PASS替代教學語意或真人驗收。
