# 我的提示詞清單（工作坊回顧）

> 讀者：參與者。時機：第80–90分鐘，先個人再小組。前置：保留今天的 `notes/` 資料夾與 Runbook 中用過的提示詞。可見性：Participant。

今天每一段都練了一個 Agentic Coding 技巧。從下表挑出 3 個你回去最會用的，請 Agent 幫你改寫成可以直接重用的提示詞，寫進 `notes/my-prompts.md`。參考 [成熟度比較](maturity-comparison.md)。

| 段落 | 技巧 | 一句話 |
|---|---|---|
| Greenfield | 先要計畫再動手；小步執行、每步驗收 | 不讓 Agent 一口氣寫完，每一小步都看證據再放行。 |
| Time Skip | 開新對話先給規則與脈絡 | 換專案就開新對話，第一件事貼規則、說明背景。 |
| 個人分析 | 讓 Agent 帶你讀陌生專案 | 請 Agent 畫系統地圖、指出規則在哪、標出文件與程式不一致處。 |
| 共同脈絡 | 把共識寫成檔案給 Agent | 小組共識寫成 `notes/shared-context.md`，之後每次請 Agent 先讀它。 |
| B1 | 用失敗測試找 Bug：重現 → 定位 → 最小修正 → 驗證 | 先讓 Agent 證明 Bug 存在，再修，再用同一測試證明修好。 |
| B2 | 請 Agent 提 2–3 個方案並比較，人來選 | 不接受第一個答案；要求比較影響與風險。 |
| B3 | 委派整件任務：工作單＋三道關卡 | 寫清楚範圍與停止條件，只在 Gate 介入。 |
| 交付 | 請 Agent 整理交付摘要，人核對 | 摘要必須附證據，未驗證如實標示。 |
| 回顧 | 把今天的技巧變成自己的提示詞清單 | 每人帶走 3 段自己會再用的提示詞。 |

## 提示詞格式（請 Agent 依此寫進 `notes/my-prompts.md`）

```text
## 技巧〈1／2／3〉：〈技巧名稱〉
什麼時候用：〈工作上的情境〉
提示詞：
〈可直接貼給 Agent 的完整提示詞；每次會變的部分用〈 〉標出〉
看什麼證據：〈Agent 做完後我要檢查什麼〉
今天的例子：〈今天哪一段用過、結果如何；沒用上就寫「未觀察」〉
```

## 兩個要帶回團隊的問題

1. 只看證據不看程式，風險在哪？公司需要什麼角色或平台補這個盲點？（例如測試全過，但程式寫法有問題）
2. 組織要導入，第一步做什麼？寫一項行動：誰、何時、用什麼證據確認。

## 完成條件

80–82分鐘選3個技巧、82–86請Agent寫成提示詞清單、86–89小組討論盲點與導入、89–90留下一項行動並匯出。用今天的實際例子；沒觀察到就寫「未觀察」，不編造效率或自主率數據。
