折抵點數價值不得超過優惠後總額的 30%（向下取整），剛好等於上限可以；以 total_fare（逐位最有利優惠後）計，不是基本票價。

# Relations
- Contexts: [membership](/contexts/membership)

# Examples
- 700 → 上限 210
- M002 企業會員 665 → 上限 199（不是 200）
- T002 成人 2 位 3,000 → 900 可折
