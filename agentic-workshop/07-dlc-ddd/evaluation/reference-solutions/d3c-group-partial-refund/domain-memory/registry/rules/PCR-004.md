手續費與退款逐位以該旅客自己的票價計算（不以 total_fare 平均），費率依取消當天的 D 決定，金額向下取整為整數。

# Relations
- Contexts: [booking](/contexts/booking)

# Examples
- ADVANCE 595、D=14 → 手續費 59、退 536
- 成人 700＋學生 525 混合團、D=1：P3＋P5 兩位學生 → 手續費 314（不是 315）
