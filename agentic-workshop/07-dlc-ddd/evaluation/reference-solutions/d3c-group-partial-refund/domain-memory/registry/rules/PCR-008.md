任何時刻 Σ退款 + Σ手續費 + Σ有效旅客票價 = Order.amount；Order.amount 與 total_fare 不變，整筆退票視為全部旅客取消、手續費 0。

# Examples
- 6 人團 4,200：取消 P0 → (490, 210, 3,500)；再取消其餘 5 人 → (2,940, 1,260, 0)
