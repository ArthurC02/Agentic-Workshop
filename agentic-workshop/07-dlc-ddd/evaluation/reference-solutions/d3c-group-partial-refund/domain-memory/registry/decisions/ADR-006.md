Membership 擁有點數餘額與全部折抵規則（最低、單位、30% 上限、換算率），Pricing 不知道點數；預留＝直接扣餘額、失敗加回，記在 Booking.redeemed_points，不建 Reservation；單一入口 MemberService.reserve_points 在一般與團體建立各呼叫一次；應付金額由 Booking 推導，付款與 Order.amount 用它，退款取 Order.amount；同步直接呼叫，不引入事件或 Loyalty Context。
