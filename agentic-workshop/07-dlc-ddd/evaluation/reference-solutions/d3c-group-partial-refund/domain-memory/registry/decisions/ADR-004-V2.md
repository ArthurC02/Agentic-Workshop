ADR-004 修訂：團體需同車廂完整連續空位、一次保留；團體付款失敗以取消、全釋放、無 Order 及紀錄補償；團體改票拒絕；已付款團體整筆退票保留，但只限未部分取消過；部分取消依 ADR-007，只釋放被取消旅客的座位、不要求剩餘座位連續。
