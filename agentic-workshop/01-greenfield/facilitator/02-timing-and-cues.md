# Greenfield 節奏與口令

> 讀者：Facilitator。時機：22 分鐘 Greenfield 全程。
> 前置：素材已發放、環境路徑確認；閱讀[主持指南](01-facilitation-guide.md)與 [G0 指令](../../../docs/instructions/02_Greenfield_Starter_Kit產製指令書.md)。
> 可見性：Facilitator 內部；口令可公開。

| 時點 | 動作與口令 | 核對 |
|---|---|---|
| 00:00 | 發放 Starter Kit：「請確認任務、需求、AC 及 Repository 可開啟，先把給 Agent 的工作規則貼進對話，再請 Agent 建好環境、跑一次測試。」 | 使用 Participant 素材，未發送內部答案；學員不自己打指令 |
| 00:02 | 開始閱讀與拆解：「請 Agent 先讀需求、掃 TODO、提出計畫，先不要修改。」 | 人確認需求、順序與風險 |
| 00:04 | 允許 Agent 修改：「確認計畫後，先完成一段能測試的核心流程。」 | 範圍由人決定 |
| 00:12 | 第一次提醒：「還有 10 分鐘。請貼變更審查提示，看 Agent 的回答和驗收對照表，有『否／不確定』就先不核准。」 | 找出阻擋，只提供所需級別提示 |
| 00:17 | 停止擴充：「請 Agent 先跑測試、整理驗收對照表；你在 /docs 試一次主要流程，並記錄未完成項。」 | 不新增非必要功能 |
| 00:20 | 產生交付摘要：「列完成／未完成、測試結果、限制，以及人和 Agent 各做什麼。」 | 結果附 Agent 實際執行的指令／輸出，未跑明記未驗證 |
| 00:22 | 結束：「停止修改，保存並提交現況；不再延長實作。」 | 收取交付摘要與證據 |

配置：閱讀與拆解 4 分鐘、Agent 執行與人員互動 12 分鐘、測試／文件／快速驗收 4 分鐘、交付與收尾 2 分鐘。17 分鐘口令用來收斂範圍，不新增額外時段。

遇環境問題，記錄耗時與採用的 Recovery；不私下延長截止時間。未完成可交付已驗證部分及限制，主持依統一條件判讀。

完成條件：七個時點皆有明確口令；人員核准計畫、要求變更審查與驗收對照表、在 /docs 試過行為，20 分鐘交付摘要、22 分鐘停止並收件。
