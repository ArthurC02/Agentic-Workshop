# Coding Agent Usage Guide

> 讀者：參與者。時機：Greenfield 22 分鐘實作。前置：閱讀任務、需求與驗收條件，環境可用。可見性：Participant。

## 1. Plan（4 分鐘）

由你主導需求理解及工作拆解，要求 Agent 提出 5–8 步計畫，先不要修改程式。核對範圍、規則與風險後，再核准執行。

通用起始提示：

> 先不要修改程式。請閱讀我提供的需求與驗收條件，掃描 Starter Repository，搜尋 `TODO(GREENFIELD`，整理待完成工作、規則對應與風險，提出 5 至 8 步計畫。列出需要我決定的問題，等待我確認。

## 2. Execute（12 分鐘）

依你核准的計畫讓 Agent 完成 TODO；你決定設計方向與優先順序。限制修改於 MVP，不任意增加外部依賴或改需求。遇到疑問先說明假設並由你確認。

## 3. Test（4 分鐘）

要求 Agent 執行 `pytest -q`，記錄指令和實際結果；核對驗收條件，補足失敗與邊界案例。辨識尚未實作而 Skip 的測試，不刪除或弱化斷言掩蓋失敗。核對完整 API 流程與 `/health`。

## 4. Explain（2 分鐘）

要求 Agent 列出修改檔案、Rule ID／AC 對應、測試結果、文件更新、風險與未完成項目。由你審查主要 Diff，確認與核准計畫一致；不要只看摘要或通過數量。

## 完成條件

計畫經你確認、測試結果可追查、主要 Diff 已審查，依 [提交清單](05-submission-checklist.md) 準備交付。未完成時如實說明，22 分鐘到即停止擴充。
