# Digital Worker Audit Record

> 讀者：Evaluation、Facilitator及交付審查者。時機：每次Digital Worker Session結束或中止。
> 前置：真實Session、Work Order與Gate證據；目前是空模板，未代表實際活動已執行。
> 可見性：Evaluation內部。來源：[治理指令 §19](../../../docs/instructions/06_Digital_Worker治理與操作規則產製指令書.md)。

## Session ID

待填：唯一識別、起訖時間／Workshop Minute；未演練不填假ID。

## Work Order ID

待填：工作命令ID／版本／連結、需求責任人。

## Agent / Tool Used

待填：實際Agent／Tool、Session識別及使用者；工具中立，無強制產品。

## Approved Context Version

待填：Context版本／來源快照／提交識別、核准人／時間；變更及重新核准記錄。

## Approved Rules

待填：本次核准Rule ID集合及版本、固定限制、Out of Scope；對照17項B3規則。

## Gate Decisions

待填：Gate 1／2／3提交、已Review證據、Decision、Approver、時間、Conditions及閉環狀態。

## Files Changed

待填：實際檔案／Diff、對應Rule與已核准範圍；無修改則明記。

## Commands Executed

待填：實際命令、工作目錄、時間、退出碼／輸出；未執行明記，勿以計畫填成執行。

## Tests Executed

待填：實際Test命令／版本、passed／failed／skip／xfail／warnings、耗時、輸出附件；未執行與未驗證項獨立列。

## Exceptions Raised

待填：EXCEPTION-DW-001是否注入、時間、提案／Constraint衝突、Decision、修正及Gate閉環；其他自發阻擋另記，不能再增加設計注入事件。

## Human Interventions

待填：Challenge／Review／停止／升級、原因、時間、後續核准；人員直接Coding若發生須如實揭露。

## Final Delivery Decision

待填：交付接受／有條件接受／退回修正／停止未交付；核准人／時間／證據及Level 1／2／3，不因全Test通過自動接受。

## Unresolved Risks

待填：未完成、未驗證、條件未閉環、風險、負責人與下一步；無已知風險也須有判定依據。

完成條件：13個固定heading皆保留，實際活動後才能填真實證據；本範本用來萃取Audit Log／Context Versioning／Session／成本與時間觀測需求，不要求本輪建立治理平台或編造演練結果。
