# Shared Context：把共識寫成檔案給 Agent

```callout info
現在在做什麼
- **情境**：每個人的 Agent 都讀過 B0，但看法不完全一樣；接下來小組要一起改同一份系統。
- **你的目標**：5 分鐘內比較大家的分析、選出主要 Agent，讓它把小組的共同脈絡（Shared Context）和規則寫成檔案。
- **今天的技巧**：**把共識寫成檔案給 Agent**。口頭講過的，Agent 下次就忘了；寫成檔案，之後每段先請它讀。
- **完成的樣子**：有 `notes/shared-context.md` 和 Skill 檔 `skills/team-rules.md`，而且沒把假設說成事實。
```

## 檢查點總覽

- **39–42 · 檢查點 1 比較各自的分析，選出主要 Agent**
- **42–44 · 檢查點 2 請主要 Agent 寫成共同脈絡檔**

## 檢查點 1 · 比較各自的分析，選出主要 Agent（第 39–42 分鐘）

① 為什麼做這一步

每個人的 Agent 先把分析濃縮成 5 行，小組才比得起來。小組要說得出一條附來源的共同事實、一個分歧，並選定主要 Agent（之後由它執行任務）和人員核准者。

② 貼給 Agent

每個人對自己的 Agent 貼：

```text
請把 notes/analysis.md 濃縮成 5 行，給小組比較用：系統地圖一句、規則在哪一句、測試現況一句、最重要的文件與程式不一致處一句、最大的不確定一句。每行標事實（來源）、假設或缺口。把這 5 行寫進 notes/analysis.md 最後新增的「5 行摘要」一節；除了這一節，不要修改任何檔案。最後只檢查、不修改：剛好 5 行、每行都標了事實（來源）、假設或缺口，標事實的行和同一份檔案前面各節一致。在對話只回覆這 5 行，再加最後一行「成功」或「失敗：」加一句原因。
```

等 Agent 濃縮時，小組先口頭決定下方討論第 1 題：誰的電腦當主要 Agent、誰當人員核准者。

③ 確認結果

Agent 最後一行已回「成功」就不用再貼；回「失敗」就貼下方「失敗時」。沒看到成功或失敗時才貼：

```text
請檢查 notes/analysis.md 的「5 行摘要」一節，不要修改任何檔案：1. 剛好 5 行，每行都標了事實（來源）、假設或缺口；2. 標事實的行都和同一份檔案前面各節的內容一致。全部符合只回「成功」；有任何一項不符，只回「失敗：」加一句原因。
```

失敗時：

```text
請重新讀 notes/analysis.md，把「5 行摘要」一節重寫成剛好 5 行，每行標事實（來源）、假設或缺口；沒有來源的不要標成事實。除了這一節，不要修改任何檔案。
```

④ 補充

```callout tip
技巧：Token 節費（加深一層）
**要摘要，不要全文。**
- 貼 5 行摘要給主要 Agent，比貼整段對話省很多 Token，主要 Agent 也不會被細節淹沒
📖 延伸閱讀：Anthropic Engineering 文章〈Effective context engineering for AI agents〉、Anthropic 官方文件〈Context windows〉；你所用工具的官方文件通常有同名章節。
```

```callout tip
💬 討論一下
**口頭講就好，不用寫下來；下一步由主要 Agent 記錄。**
1. 誰的電腦當**主要 Agent**？誰當**人員核准者**？（等 Agent 濃縮時先決定）
2. 每個人把 5 行傳到小組聊天室（或念出來）
3. 大家說的一樣、而且都附得出來源的，就是共同事實
4. 說法不同或沒證據的是分歧：要重跑哪個測試或對照哪條規則，才分得出對錯？
5. 說完，主要 Agent 那位把一兩句分工與共識打進聊天室，下一步直接複製
```

## 檢查點 2 · 請主要 Agent 寫成共同脈絡檔（第 42–44 分鐘）

① 為什麼做這一步

口頭講過的，Agent 下次就忘了；寫成檔案，之後每段才能先請它讀。小組判斷主要 Agent 的複述有沒有把分歧或假設說成事實，有沒有自己加修改計畫。有的話，請它修正檔案。

② 貼給 Agent

在**主要 Agent** 的對話裡一次貼完三樣再送出：

1. 下面這段提示詞。
2. 剛才打進聊天室的一兩句分工與共識：主要 Agent 在誰的電腦、人員核准者是誰、口頭說好的共識與分歧。
3. 其他成員的 5 行摘要，從聊天室複製即可。

只有你一人時（例如晚到），第 3 樣寫「沒有其他成員；共同事實改為自己的分析中附來源的事實」。

```text
先不要修改程式，也不要提出修改計畫。我們要把小組共識寫成 notes/shared-context.md，再把小組的工作規則寫成 skills/team-rules.md。這段後面我附上了兩樣東西：小組的分工與口頭共識（主要 Agent 在誰的電腦、人員核准者是誰、共識與分歧），以及其他成員的 5 行分析摘要。少了哪一樣，只問那一樣。請依序做：
1. 讀我附上的分工、共識與摘要；你自己的分析只讀 notes/analysis.md 的「5 行摘要」一節，一起比較。
2. 寫成 notes/shared-context.md，分五節：共同事實（多人一致、附來源：文件位置、測試名稱或實際執行結果）、仍有分歧（附驗證方式：重跑哪個測試、對照哪條規則）、已知限制（只記限制，不預先核准修改）、待決事項（要等任務揭露才能決定的事）、分工（主要 Agent 與核准者）。證據不足的寫成假設，不要寫成事實。
3. 建立 skills/team-rules.md（給 Agent 的工作說明，之後每段開工都會先讀），固定三節：開工先讀（notes/shared-context.md）；工作規則（把這個對話一開始我貼給你的 7 條工作規則原文抄進來，第 4 條要包含「因規則改變而過時的期待值，須列出測試名稱與規則編號（Rule ID），經我核准後才更新」；對話裡找不到就先問我）；回報格式（驗收對照表欄位：編號、白話內容、結果（通過／失敗／未驗證）、依據的測試名稱；改了哪些檔案與原因；只給摘要不貼完整輸出；做完停下等我）。
4. 寫完用 3 句以內的白話複述重點，指出你認為證據不足或互相矛盾的地方（最多 3 條）。
5. 最後只檢查、不修改：shared-context.md 五節都有內容、共同事實都附了來源；team-rules.md 有開工先讀、工作規則（7 條，第 4 條含過時期待值須經核准才更新）、回報格式三節；用 git status 確認除了 notes/ 與 skills/ 沒有修改任何檔案。全部符合在最後一行只寫「成功」，否則寫「失敗：」加一句原因。然後停下等我們確認。
```

主要 Agent 寫檔時，其他人先填頁尾表單第 1 題「我在小組的角色」，再讀下方 ④ 的 Skill 小卡；Agent 複述完，小組一起看複述。

③ 確認結果

Agent 最後一行已回「成功」就不用再貼；回「失敗」就貼下方「失敗時」。沒看到成功或失敗時才貼：

```text
請檢查下列三件事，不要修改任何檔案：1. notes/shared-context.md 的五節都有內容，共同事實都附了來源；2. skills/team-rules.md 有開工先讀、工作規則（7 條，第 4 條含過時期待值須經核准才更新）、回報格式三節；3. 除了 notes/ 與 skills/，沒有修改任何檔案（用 git status 確認）。全部符合只回「成功」；有任何一項不符，只回「失敗：」加一句原因。
```

失敗時：

```text
請用白話說明哪一項不符，只補齊或修正 notes/shared-context.md 與 skills/team-rules.md；改到其他檔案就用 Git 還原。不要提出修改計畫，改完再複述一次重點。
```

④ 補充

```callout tip
技巧：Skill（可重複使用的工作說明）
**Skill 是把反覆要用的做法寫成 Markdown 檔，放在專案的 `skills/` 資料夾。**
- 由 Agent 建立；之後只要說「請先讀 skills/… 並照做」，不用重貼
- B1 起每段提示詞第一句都是「請先讀 skills/team-rules.md」
- 工具內建的 Skill 功能另有固定格式，今天不需要
📖 延伸閱讀：Anthropic 官方文件〈Agent Skills〉、OpenAI Codex 官方文件〈Custom instructions with AGENTS.md〉、GitHub 官方文件 Copilot〈Adding repository custom instructions for GitHub Copilot〉；你所用工具的官方文件通常有同名章節。
```

## 完成後想一想

先自己想 30 秒，再和旁邊的人聊；趁等 Agent 回報時聊，這段不另開全場分享。

1. **觀察**：比較 5 行摘要時，哪一條大家說法不一樣？最後是靠什麼證據（文件位置、測試名稱或實際執行結果）決定寫成事實還是分歧？
2. **技巧**：如果不寫 `notes/shared-context.md` 和 `skills/team-rules.md`，只靠口頭講好，下一段換人或開新對話時會發生什麼？你的團隊有哪些「每次都要重講一次」的規則，值得寫成 Skill？
3. **延伸**：主要 Agent 只有一個，但小組有好幾個人。接下來要真的改程式時，誰說了算、怎麼避免大家各自叫 Agent 改？
