## 檢查點 2 · Gate 1：確認 Agent 懂需求（第 64–66 分鐘）

① 為什麼做這一步

Gate 1 確認意圖：Agent 理解的要什麼、為什麼、限制，要和任務卡一致，理解錯了後面做得再快都是白做。逐題對照卡上附的任務卡原文，都對得上就核准；標「待小組確認」的題目由你們決定，第 66 分鐘前回覆。

② 貼給 Agent

看完 Gate 1 卡直接回覆，選一種：

- **核准**：每題都對得上，「要你決定」照 Agent 的建議
- **核准，A 改成…**：核准，但某一題不照建議，把你們的答案寫上
- **附條件：…**：例如「附條件：第 3 題請補上付款失敗要發取消通知」
- **退回：…**：例如「退回：第 2 題把車廂寫錯了」

Agent 會自己記下核准人和時間，接著交 Gate 2 卡。回覆後，在頁尾「B3 Gate 決策」選 Gate 1 的決策。

③ 確認結果

## 完成後想一想

先自己想 30 秒，再和旁邊的人聊；趁等 Agent 回報時聊，這段不另開全場分享。

1. **觀察**：三道 Gate 裡，哪一道你最想退回、或真的退回了？例外事件時，你們是靠工作單的哪一句做出決定的？
2. **技巧**：如果沒有工作單和 Gate，只說「把團體訂票做完」就放手，Agent 停下來問你的那些時刻會變成什麼？你工作上哪一件事可以這樣委派，Gate 要設在哪？
3. **延伸**：Agent 做完了，但主管沒有看過任何一個 Gate。你要交給他什麼，他才能在 1 分鐘內判斷能不能收？
