# 歡迎來到 Agentic Software Development 實作工作坊

今天用虛構的車票預訂服務 **Smart Ticket Platform**，在 90 分鐘內和 Agent 走完需求、計畫、執行、測試與交付。

## 今天的流程

每段練一個帶得走的技巧。（ ）內是 Agent 在這段的角色，〔 〕內是提示詞示範的 Agent 技巧。技巧第一次用到時才說明，現在記得名稱就好。

- **00–07 開場**
- **07–29 Greenfield**（Tool）：給 Agent 一份規則；先要計畫再動手；小步執行、每步驗收。〔Prompt 結構、結構化輸出〕
- **29–33 Time Skip**（Teammate）：開新對話先給規則與脈絡。〔Token 節費〕
- **33–39 個人分析**（Teammate）：讓 Agent 帶你讀陌生專案。〔Token 節費、模型選擇與推論強度、結構化輸出〕
- **39–44 共同脈絡**（Teammate）：把共識寫成檔案給 Agent。〔Skill、Token 節費〕
- **44–52 B1**（Teammate）：用失敗測試找 Bug。〔Skill、Token 節費〕
- **52–63 B2**（Teammate → Digital Worker）：請 Agent 提 2–3 個方案並比較，人來選。〔結構化輸出、推論強度〕
- **63–76 B3**（Digital Worker）：委派整件任務：工作單 ＋ 三道關卡。〔Prompt 結構、Skill、結構化輸出、模型選擇、Token 節費〕
- **76–80 交付**（Digital Worker）：請 Agent 整理交付摘要，人核對。〔結構化輸出〕
- **80–90 回顧**：把今天的技巧變成自己的提示詞清單。

Greenfield 個人做；第 39 分鐘起和旁邊 2–3 位組成小組。

## Tool → Teammate → Digital Worker

三者差在「人怎麼介入」，不是「人寫多少程式」：

- **Tool（工具）**：你一步一步下指令，每步看證據驗收。
- **Teammate（隊友）**：Agent 一起分析、提出選項；你核准計畫，它才動手。
- **Digital Worker（數位員工）**：你先定好範圍，只在核准關卡（Gate）做決定；Agent 在範圍內自己做。

今天全程**你不寫程式、不讀程式，也不自己打指令**，這些都交給 Agent。你負責決定、核准，並用 Agent 交的證據驗收。

## 如何使用這份 Runbook

- **投影和 Runbook**：投影告訴你現在做到哪、何時停；Runbook 告訴你怎麼做。看到「⏸ 看投影」就抬頭看投影。
- **每個檢查點分四塊**：
  - ① 為什麼做這一步：要你判斷的事也寫在這裡。
  - ② 貼給 Agent：按「複製」再貼上；有 Windows／macOS 分頁就選你的系統。
  - ③ 確認結果：再貼一段，Agent 只會回「成功」或「失敗」。回「失敗」就貼下面「失敗時」那段。
  - ④ 補充：有需要才出現。
- **要你決定時**：Agent 會停下來問，你回「同意」或「改成…」就好。
- **時間**：檢查點標的是**最晚**完成的分鐘；提早做完就直接做下一個。
- **便利貼**：桌上有綠色、紅色便利貼。③ 回「成功」就在筆電上緣貼綠色；卡住，或貼了「失敗時」還是不行，就貼紅色，主持人會走過去。開始下一個檢查點時撕下。
- **解鎖**：段落開始時，主持人在投影公布解鎖碼，輸入在該段的解鎖框。大小寫、空白和連字號都不影響。
- **復原包（Recovery）**：進度落後時，主持人會在第 52 或第 63 分鐘私下給你們另一組解鎖碼。
- **下載**：程式包在 Runbook 裡，解鎖後按下載按鈕取得 ZIP。
- **紀錄**：計畫、分析和驗收紀錄都由 Agent 寫進專案的 `notes/` 資料夾，你不用抄。
- **表單**：只記「人的決定」，會自動暫存；離開前按回顧頁的「下載全部填寫內容（ZIP）」一次匯出。
- **💬 討論一下**：口頭講就好，不用寫下來。
