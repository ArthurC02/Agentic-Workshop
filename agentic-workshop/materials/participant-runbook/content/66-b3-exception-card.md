# 例外回應卡

## 例外事件：60 秒內做決定

① 為什麼做這一步

例外提議可能把 Agent 帶出 Gate 2 核准的範圍，所以先停下，由人決定。對照 Agent 抄給你的工作單原文，60 秒內回覆；時間緊就用 30 秒口頭判斷。

② 貼給 Agent

貼下方提示詞。Agent 會先問投影上的事件短句（它自己提過就不問），再用 3 行說明提議並抄出原文；你回一行，例如「1 不確定 2 附條件：先列出要改哪些檔案」。

```callout sync
⏸ 看投影：Agent 問事件內容時，照抄投影最下面粗體的「事件：……」，連「為什麼」一起抄，不用打整張卡
```

```text
主持人剛宣布了例外事件。請先停止所有修改，依 skills/b3-work-order.md 第 8 節「例外事件」處理。
```

③ 確認結果

Agent 回覆的最後一行寫「自我檢查：成功」就往下；寫「失敗」就貼「失敗時」。沒看到這一行才貼：

```text
請實際打開 notes/b3.md 並執行 git status 再回答，不要憑記憶，也不要修改任何檔案：1. 「例外事件」段落寫了提議內容、影響範圍與對照的原文；2. 照原話記著我的範圍判斷與決定、核准人、時間，以及你告訴我的下一步；3. 我決定之後你沒有修改任何程式。全部符合只回「成功」；有任何一項不符，只回「失敗：」加一句原因。
```

失敗時：

```text
請停止所有修改。把我剛才那一行回覆照原話補進 notes/b3.md 的「例外事件」段落，寫清楚依這個決定要停止什麼、可以做什麼；我決定後改過的程式，不在允許範圍內就用 Git 還原。補完告訴我。
```
