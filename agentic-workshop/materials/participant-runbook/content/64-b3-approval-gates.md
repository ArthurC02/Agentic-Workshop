> 本頁內容取自 B3 參與者文件 `03-approval-gates.md`，在 [B3 流程](#b3)檢查點 1 連同全文交給主要 Agent，讓它知道每個 Gate 要交什麼。每道 Gate 由 Agent 先用固定的「Gate 回報格式」整理成決策卡問你，你回一句決定；理由、條件、核准人與分鐘由 Agent 照原文寫進 `notes/b3.md`，你只在 B3 流程頁的「B3 Gate 決策」選決策。

```callout info
由人決策，Agent 只照抄
Agent 不代填核准。核准代表允許下一步，不代表驗收或測試 PASS（通過）；PASS 必須有實際驗證證據。

- Gate 1 需求理解：全場第 66 分鐘決策，核准需求才進入設計。
- Gate 2 影響分析與設計：全場第 69 分鐘決策，此 Gate 核准且相關條件已解除後，才可修改程式。
- Gate 3 交付審查：全場第 75 分鐘審查，依據是 Agent 的驗收對照表與變更審查答案，不看程式。
```
