# 回顧：把今天的技巧變成自己的提示詞清單

```callout info
現在在做什麼
- **情境**：工作坊結束後，你回到自己的專案，身邊沒有 Runbook。
- **你的目標**：帶走 3 段自己會再用的提示詞，並和小組留下一項帶回團隊的行動。
- **今天的技巧**：**把今天的技巧變成自己的提示詞清單**。技巧記在腦中很快會忘；寫成可直接貼上的提示詞，下次打開 Agent 就用得上。
- **完成的樣子**：`notes/my-prompts.md` 有 3 段你的提示詞；你填完 4 欄的回顧表並匯出所有表單。
```

用 **10 分鐘**：先個人選技巧，請 Agent 寫成提示詞，再小組討論，最後留下一項行動。

```callout warning
用證據回顧，不排名、不編數據
- 「今天的例子」寫本次實際發生的事；沒觀察到就寫「未觀察」。
- 不排名、不比程式碼量。成熟度指工作安排與責任配置，不是人員排名或工具產品能力榜。
- 沒有活動計時，不編造效率或 Agent 自主完成的比例。
```

## 檢查點 2 · 請 Agent 寫成你的提示詞（第 82–86 分鐘）

- [ ] 用你自己的 Agent（任何一個 Agent 對話都可以），貼上上方「提示詞格式」與下方提示詞。`notes/` 在組員電腦上時，直接把 Runbook 裡對應段落的提示詞一起貼給 Agent：

```text
我今天練習了下列 3 個 Agentic Coding 技巧：〈技巧 1〉、〈技巧 2〉、〈技巧 3〉。
請讀 notes/ 資料夾裡今天的紀錄（找不到就用我貼上的提示詞），依附上的「提示詞格式」，把這 3 個技巧各寫成一段我回到自己的專案可以直接貼上的提示詞，寫進 notes/my-prompts.md。
- 不要綁定今天的 Smart Ticket 專案；會變的部分用〈 〉標出。
- 每段都要寫「看什麼證據」：Agent 做完後我要檢查什麼。
- 「今天的例子」只寫 notes 裡真的有的事；找不到就寫「未觀察」，不要編。
寫完把 3 段提示詞貼在對話給我看。
```

- [ ] 讀一遍 Agent 寫的提示詞；不像你會說的話，就請 Agent 改到你願意直接用為止。

**看什麼證據**：`notes/my-prompts.md` 有 3 段提示詞，每段都有「什麼時候用」「看什麼證據」。

## 檢查點 3 · 小組討論盲點，留下一項行動（第 86–90 分鐘）

- [ ] 小組先討論一題：**只看證據不看程式，風險在哪？公司需要什麼角色或平台補這個盲點？**（例如測試全過，但程式寫法有問題，今天的流程抓不到）用今天的實際例子回答，結論填表單第 2 欄。
- [ ] 再討論：組織要導入今天的做法，第一步做什麼？可以從背景資料、規則、流程、平台或人員責任挑一項。只想到「Agent 更聰明」時，改問自己：可以改哪份背景資料、哪個 Gate，或哪個可驗證的控制？
- [ ] 第 89 分鐘停止新議題，填表單第 3 欄：一項帶回團隊的行動，具體到說得出誰、何時、用什麼證據確認。沒把握的寫「待研究」，不編造結果。
- [ ] 填表單第 4 欄：小組 B3 的實際完成等級。
- [ ] 匯出所有表單（見下方）。`notes/my-prompts.md` 請自己帶走。
