# 回顧與組織導入：把做法帶回團隊

> 讀者：學員。時機：25 分鐘回顧講解。前置：已聽過前四段，或手邊有自己的 `notes/` 與 `skills/` 紀錄。

本段以概念與判斷為主；範例提示詞選用，貼給你自己的 Coding Agent（能讀寫檔案、協助寫程式的 AI 助手），結果由你檢查。

## 1. 從做完一件事，到帶回團隊

最後一段：整理前四段，決定你回去要用什麼。

- **三件事**：怎麼選介入方式、怎麼把做法寫成 Skill（技能檔）、怎麼在組織裡先試。

- **怎麼聽**：對照你自己的真實工作，不必記步驟。

**人工確認**：想一件你下週真的會交給 Agent 的工作，後面每頁都拿它來對照。

## 2. Tool、Teammate、Digital Worker

差別不在 Agent（AI 助手）多聰明，而在人什麼時候介入。

Tool：人一步一步帶 → Teammate（隊友）：人核准計畫 → Digital Worker（數位員工）：人只在關卡介入

- **Tool**：人拆解、Agent 執行；每步都看結果。

- **Teammate**：共同分析與比較，人選方案。

- **Digital Worker**：在核准範圍內交付；人守邊界與簽收。

**人工確認**：你剛才想的那件工作，過去是用哪一種方式做的？

## 3. 一件真實工作，怎麼選？

看三件事：做錯的代價、能不能復原、拿得到什麼證據。

- **風險高、難復原**：退回 Tool 或 Teammate，每一步都留人確認。

- **風險低、可復原**：可委派整件，只設關卡。

- **證據不足**：先補證據來源，再提高自主程度。

**人工確認**：能說出這件工作「做錯會怎樣、怎麼復原、憑什麼證據放行」。

## 4. 六個技巧，各自加深一層

每個技巧都在後面的階段被用得更嚴格。

- **提示詞結構、結構化輸出**：從一份計畫，到工作單與固定欄位的回報。

- **模型選擇、推論強度**：機械性工作用快的；分析、取捨、審查用強的。

- **Token（詞元）節費、Skill**：一任務一對話、只讀指定檔、做法存成檔案。

**人工確認**：六個裡，哪一個你這週就能用？

## 5. 重複的做法，寫成 Skill

Skill 是 skills/ 裡的 Markdown 說明檔（本課程用簡化版；工具內建的另有固定格式）。前面照課程步驟寫，這次從你自己做過的工作挑一個寫。

- **適合寫**：你已做過兩三次、步驟固定、結果能檢查。

- **不適合寫**：每次都不一樣、或只有你判斷得出對錯的事。

**人工確認**：你能說出這個做法每次的步驟與成功的樣子，才值得寫。

## 6. 從真實工作，抽出一份 Skill

請 Agent 看你做過的紀錄，整理成四段。

挑一個重複做法 → 讀紀錄 → 寫成 Skill → 人檢查證據

- **四段內容**：何時用、步驟、要交的證據、回報格式。

- **人要判斷**：步驟是不是你真的會做，而不是 Agent 想像的。

### 交給 Agent 的指令

請讀 notes/ 裡的紀錄，找出我做過兩次以上、步驟固定的一個做法，先告訴我是哪一個並等我確認。確認後寫成 skills/ 裡的一份檔：何時用、步驟、要交的證據、回報格式。紀錄沒有的寫「未觀察」，不要編。寫完停下等我。

**人工確認**：每一步都能在你的紀錄找到出處；找不到的已標「未觀察」。

## 7. 導入靠證據，不靠表格

Agent 寫進 notes/ 與 skills/ 的紀錄，就是能說服組織的材料。

- **notes/**：做了什麼、證據在哪、還缺什麼。

- **skills/**：可被別人重複使用的做法。

- **不是填表**：沒有證據的簽核，等於沒有關卡。

**人工確認**：拿一段紀錄給同事看，他能不能不問你就看懂？

## 8. 量什麼，才知道有沒有用

先定口徑再量；量不到的就寫「未觀察」。

- **時間**：執行、審查、重工各花多久。

- **品質**：退回幾次、哪一關攔下問題。

- **成本**：Token 用量與模型選擇。

**人工確認**：每個數字都有分子、分母與來源；沒有就不報比例。

## 9. 先試哪裡？

挑風險低、可復原、證據好取得的一件小事。

選一件 → 寫規則與關卡 → 小範圍試用 → 看證據再擴

- **先試**：重複性高的文件、測試整理、讀陌生程式。

- **暫緩**：涉及權限、金流或難復原的變更。

**人工確認**：試用有責任人、有期限、有成功與停止的證據標準。

## 10. 還是需要人的地方

只看證據、不看程式，是這套做法的設計盲點。

- **看不到的**：測試全過，但寫法或安全有問題。

- **仍需人**：範圍、授權、風險取捨、簽收責任。

- **補法**：指定審查角色，或加自動檢查。

**人工確認**：能說出誰替交付簽名負責，以及他還需要看到什麼。

## 11. 帶回去的三件事

選介入方式、寫自己的 Skill、小範圍先試。

- **下週**：把一個重複做法寫成 Skill。

- **下個月**：挑一件小事，帶著證據試用。

- **隨時**：沒證據的，標「未驗證」。

**人工確認**：寫下一項行動：誰、何時、做什麼、用什麼證據確認。

## 完成條件
帶走三項：一份依風險、可逆性與證據選介入方式的判斷、一個寫成 Skill 的重複做法，以及一項有責任人與驗證方式的導入行動。
