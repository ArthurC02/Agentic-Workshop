Tool · 07–29

由人主導，完成個人任務

人理解需求、選擇設計、拆解任務並審查；Agent 協助撰寫程式、測試與文件。

Teammate

個人分析 → 小組比較

Agent 分析既有程式與設計取捨；人比較各自的分析，整理共同脈絡（Shared Context：小組整理出的共同事實）。

Digital Worker

Agent 主導交付

Agent 依三個核准關卡（Gate）與時間限制執行；人負責質疑假設、核准及審查。

三種角色描述協作分工；人仍對最後的決策與成果負責。

主持口述版（Digital Worker Debrief Notes）：「Tool（工具）階段人理解需求、選設計與拆解，Agent協助；Teammate（隊友）比較Agent分析、形成共同脈絡（Shared Context）；Digital Worker（數位員工）由Agent主導交付，人保留質疑假設、核准與檢視（Review）。責任轉移與重新分配，不因Agent自主而消失。」

Maturity 表下原文：「成熟度指工作安排與責任配置，不是人員排名或工具產品能力榜。」

注意：此處只講角色與責任；三種角色不是產品分類，也不代表每項工作都應提高自主程度。不提前說明 B1／B2／B3 任務內容或 Bug（29 分鐘前不發 B1／B2／B3 或 Bug 根因）。
