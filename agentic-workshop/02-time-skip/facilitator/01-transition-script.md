# Time Skip 主持轉場稿

> 讀者：主持人。時機：第29–33分鐘。前置：統一 B0 已驗收並可發放。可見性：Facilitator，不給學員。

29分鐘請宣布：「我們快轉到上線12個月後。請停止自己的 Greenfield 開發，接手同一份既有系統。這次先各自請 Agent 理解，再比較證據與結論。」

30分鐘發放 B0 與接手文件；31分鐘確認所有人使用相同版本及環境；32分鐘提醒測試有若干失敗、文件要交叉驗證；33分鐘開始6分鐘個人分析，禁止修改。

觀察：是否仍使用自己的 MVP、是否提前修程式、是否有環境阻塞。只能回答操作與活動範圍；不揭露學生率錯誤、檔案位置、失敗數或文件落差位置。

停止條件：多人版本不一致或環境不可啟動時先使用已驗收發放件處理，不讓學員各自更換基線。33分鐘停止背景敘述，進入分析。

## 完成條件

全員接手同一 B0、知道個人分析與小組整合順序，轉場在4分鐘內完成；實際時間需另行演練。
