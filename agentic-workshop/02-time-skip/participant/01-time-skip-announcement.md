# 時間快轉：12 個月後

> 讀者：參與者。時機：第29–33分鐘。前置：停止 Greenfield 個人實作。可見性：Participant。

Smart Ticket 上線已經過12個月。系統增加會員、優惠、改退票、通知、座位與稽核，程式、測試及歷史決策也一起成長。

請停止使用自己的 Greenfield Repository，改接手主持人統一提供的 B0（已上線的既有程式）。先理解既有系統與證據，再決定怎麼改。Agent 的角色從工具（Tool）轉為隊友（Teammate）：各自請 Agent 分析、比較判斷，再整合成小組的共同脈絡（Shared Context）。接手的第一件事：在 B0 開新的 Agent 對話，先貼規則、說明背景。你仍然不寫程式、不讀程式、不自己打終端機指令；Agent 負責操作並用白話說明，你負責判斷與核准。

## 完成條件

已切換到同一份 B0，知道先分析再修改，準備閱讀交接資料。
