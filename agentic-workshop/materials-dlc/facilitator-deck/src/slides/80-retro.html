第 174 分前完成→ 下一步：檢查點 3 挑選提示詞與一項行動

說（04:00／第 169 分）：「第 169 分。請 Agent 把今天每個人工把關點列出來：來源與定義、夥伴核准、選項與交接單、反事實檢查、查證引用，標出哪一步一個人就能完成。然後口頭討論：哪一步真的擋住過今天的錯？record-approval 只比對字串、同機雙身分也能過，自己核准自己只是照流程做完，這和真正由他人審查差在哪？」

看：是否討論到簽章只證明『誰簽了』，不證明『審得夠不夠』。

介入訊號：偏向工具比較 → 拉回今天的證據。

新概念：這裡第一次介紹評估 Agent 的成果（eval），花 30 秒講：拿最後一次人核准的模型（git log 最上面（最新）一個訊息含「套用」的 commit）當基準答案，compare-registry 比對現在的模型；extra 是核准後 Agent 新寫、還沒人審的，missed 是核准過卻不見的。分數只比結構，要讀清單。再看 overall_independent：引用和基準答案一字不差的配對（copied_evidence）是核准後沒動過、照抄來的，overall 1.0 幾乎全靠它們（D3c Recovery 實測 57 個配對裡 52 個）；誠實的分數只算 Agent 自己寫的部分。

看：missed 不是 0 的組，請 Agent 指出是哪一段改掉的：這就是人工把關沒擋住的地方。
