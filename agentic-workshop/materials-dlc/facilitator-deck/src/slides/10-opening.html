DLC 是延伸課程，原指遊戲的追加內容。D1–D4 是今天四段的代號，D3 再分 a、b、c 三張需求卡。

開場前：選定計時者與證據記錄者。接著講「為什麼」「怎麼進行」兩頁（共約 2 分鐘），再翻到解鎖頁；10:00 計時在總覽頁按 T 啟動。

說：「主課你們看過 Agent 從工具、隊友，到能獨立執行任務的數位員工。今天 180 分鐘加課，主題是：怎麼帶著 Coding Agent 做 DDD。Agent 找證據、做苦工；你定義模型、做決定、看證據驗收。domain-memory 只是保存共用模型的工具。」

前提：對象是已完成主課的學員；DDD 概念透過和 Agent 一起做真實決定來學，不另開理論講堂；domain-memory 只保存共用模型，指令全由 Agent 執行。

為什麼

Agent 會忘、說法會亂：先和 Agent 建一份共用模型

問題

名詞與邊界各說各話

文件、ADR（架構決策紀錄）、程式、測試各說各話，Agent 只能猜。

做法

Agent 找證據，人定義模型

Agent 附證據提草稿，夥伴審查核准後才算事實

目的

照模型設計，用測試證明

Agent 依已審查事實設計、實作，再用測試證明規則真的守得住。

說（解鎖前，約 1 分鐘）：「Agent 每次對話都從零開始，同一件事還常換說法。今天你們先和 Agent 建一份有證據、經審查的共用模型，再照它做三個變更。」

注意：只講動機，不示範指令；不提前說明 D3 情境細節。

  2. 35–60D2 · 審查核准

投影告訴你做到哪、何時停；Runbook 告訴你怎麼做。③ 回『成功』貼綠色便利貼；卡住貼紅色，主持人會走過去

說（解鎖前，約 1 分鐘）：「60–70 分休息。每段都從 Runbook 解鎖，投影會列出每個檢查點要貼哪一段、要判斷什麼；每個檢查點貼提示詞，Agent 做完停下回報，需要決定時你回一句話，紀錄由 Agent 寫。每段結尾先小組討論，再把結論記進表單。D3 三個情境全做，依序累積。」

⏸ 看投影：Runbook 只在真的要抬頭時放深藍色「⏸ 看投影」提示（解鎖、找夥伴、停手、揭曉、Recovery）；投影上對應的頁右上角有同一個標記。說一次：「看到它就抬頭。」

便利貼：每人桌上綠、紅便利貼各一疊。③ 回「成功」貼綠色；卡住、或貼了「失敗時」還是不行就貼紅色。每個檢查點截止時掃一眼全場顏色：紅色先過去；截止時還沒貼綠色的，走過去問一句卡在哪。

規則：每段有獨立解鎖碼；卡住時主持人才視需要私下提供 Recovery，Recovery 不作為小組成果評分。

只給路線圖：這裡只念段落名稱，不解釋 DDD 概念；每個概念在第一次用到的檢查點頁才講（講者備註會提醒「這裡第一次介紹 X」）。Runbook 的歡迎頁也只列各段會學到的名稱。

說（約 20 秒）：「10 分鐘：先把環境備好。四個檢查點，每個都分四塊：① 為什麼、② 貼給 Agent、③ 確認結果、④ 補充。③ 回『成功』就往下；回『失敗』就貼『失敗時』。提示詞都在 Runbook；檢查點頁會列出要貼哪一段、要判斷什麼、幾分前完成。」

檢查點頁備註的「看」：學員自己判斷的項目對應 Runbook ①（例如 D1 選來源、D2 核准），Agent 回報的數字與檔案（例如 76 passed、SHA OK 80 files）由 ③ 確認結果檢查。之後每段都一樣。

操作：本頁按 T 啟動 10:00 段落計時（00:00＝第 0 分）。說完翻到檢查點 1；之後每到時間點翻到下一個檢查點頁，本頁時間軸會依計時自動標示目前檢查點（各段都一樣）。配對放到檢查點 4（第 8 分）。

降級：第 10 分鐘仍有人環境檢查未過 → 兩人一機繼續，D1 起以夥伴機器為主；記錄耗時，不延長本段。
