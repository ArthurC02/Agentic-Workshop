# 交接與回顧：讓下一個 Agent 接得上

> 讀者：學員。時機：DDD 延伸課 D4 與回顧之後的 25 分鐘講解。前置：已聽過前三場 DLC Speech，手邊有自己的 notes/ 與 docs/handoffs/。

本場講概念與技巧，不需要寫程式或打指令。頁面上的提示詞是示範，想試再貼給自己的 Agent；沒有實際執行的結果，一律視為未驗證。

## 1. 明天換人接手

接手的人只看得到 Repo、共用模型與一份交接單；今天的對話他看不到。

- **D4**：檢查模型落後程式多少，寫給下一個 Agent 的交接單。

- **回顧**：從紀錄找證據：哪些把關真的有用。

**人工確認**：如果明天換你接手，你最先打開哪一個檔？

## 2. 模型會落後程式

D3 加了新程式與新規則；D1 確認的來源多了新檔案，Agent 回報「來源過期」是正常的。

- **不要硬修**：來源過期不是錯誤，是模型需要下一次審查。

- **寫進 Unknowns（未知事項）**：留給下一次成對核准處理。

**人工確認**：Agent 回報來源過期時，有沒有想自己「修好」它？

## 3. 改變的規則，寫成新候選

D3 改變了哪些規則，Agent 整理成新候選；它們要等下一次核准才成為事實。

- **候選附證據**：每筆指到 D3 的實作與測試行號。

- **不冒充事實**：沒經夥伴核准的，一律標候選。

**人工確認**：Agent 有沒有把任何一筆 D3 的新規則寫成已審查事實？

## 4. 交接單的七段

給下一個 Agent 的交接單用固定的七段；沒有內容的段寫「無」與原因。

- **時間不夠時**：至少寫 Unknowns，其他段寫「未完成」。

```text
Domain facts        已審查事實與候選，分開列
Forces              影響決定的考量與限制
Decision            做了什麼決定、為什麼
External systems    外部服務與它的回應分類
Unknowns            還沒決定、還沒證明的事
Proof obligations   每條規則對應的測試
Counterfactual check  實際看到 killed 的規則；沒有寫「未證明」
```

**人工確認**：只看這份交接單，接手的人知道哪些事還沒決定嗎？

## 5. 技巧：只准引用查得到的 id

Agent 會自信地寫出不存在的 id；請它逐一查證每一個引用。

- **為什麼會錯**：Agent 照格式「合理地」編出 id。

- **人看什麼**：表裡有沒有「查不到」或「狀態不同」。

### 交給 Agent 的指令

不要修改任何檔案。請把這份交接單裡引用的每個 id 與檔案路徑列出來，逐一到共用模型與 Repo 查證：查得到、查不到、或狀態不同（例如寫成已審查事實但其實是候選）。列成表，查不到的不要自己補，列完停下。

**人工確認**：你的交接單裡，有沒有一個 id 第一次查不到？

## 6. 請 Agent 從紀錄整理證據

回顧時，Agent 從 notes/、交接單與版本紀錄整理證據，人只判斷；沒有證據就寫「未觀察」。

- **不憑印象**：「感覺有幫助」不算，要指到紀錄裡的哪一行。

- **未觀察也是答案**：沒有紀錄，就不宣稱有效果。

**人工確認**：你的回顧裡，有沒有一句沒有證據、卻寫成了結論？

## 7. 哪些把關真的擋住錯

把今天每個人工把關攤開，判斷哪一步擋住過錯誤、哪一步只是照流程做完。

來源與定義 → 夥伴核准 → 選項與交接單 → 反事實檢查 → 查證引用

- **擋住過**：紀錄裡找得到它抓到的錯。

- **只是做完**：做了，但沒有改變任何結果。

**人工確認**：哪一步你覺得有用，但紀錄裡找不到它擋住過什麼？

## 8. 說清楚：簽章是教學示範

兩人在同一台機器上，今天的成對簽章不能證明真的有兩個人審查過。

- **為什麼不能**：任一人都拿得到私鑰；推送前的檢查也能被跳過。

- **它的用處**：讓你看見每一步留下什麼證據。

**人工確認**：要證明「真的有另一個人審查過」，今天還缺什麼？

## 9. 回到團隊需要什麼

真實團隊要讓「另一個人核准」變成做不到假的事。

- **不同的人與機器**：每人自己的金鑰，私鑰不離開本人。

- **伺服器端檢查**：例如受保護分支（沒核准不能合併），不靠本機。

- **一個持鑰角色**：誰負責審查共用模型，要有人擔任。

**人工確認**：你的團隊裡，誰適合擔任共用模型的審查者？

## 10. 帶走一個提示詞、一項行動

回到自己的專案時沒有 Runbook；挑今天最有用的提示詞，和一項有人負責的行動。

- **提示詞**：存進 notes/，下次直接貼給 Agent。

- **一項行動**：寫出誰做、何時、怎麼知道做到了。

**人工確認**：你的行動，說得出「怎麼知道做到了」嗎？

## 11. DLC 帶走什麼

Agent 找證據、做苦工；人定義模型、做決定、用證據驗收。

共同語言與邊界 → 審查與核准 → 依模型做需求 → 交接 → 回顧

- **四場的主線**：候選要經人核准才成事實；每條規則要有測試守著。

- **回到工作**：先從一個名詞、一條規則開始寫下來。

**人工確認**：回到開場：明天接手時你打開的那個檔，今天有寫好嗎？

## 完成條件
說得出模型為什麼會落後程式、交接單為什麼只准引用查得到的 id；能區分今天哪些人工把關真的擋住錯誤，也說得出成對簽章的限制與真實團隊需要的條件；帶走一項回到團隊的行動。
