# 主課程與 DLC 的 UI／UX 走查

本次範圍是兩版離線 Runbook、主持簡報與兩者的操作銜接。依實際操作逐輪修正；停止條件是完整情境走查沒有新發現的可重現問題，不是宣稱所有人的使用體驗都已完美。

## 已重現並處理的問題

| 問題 | 處理 | 證據 |
|---|---|---|
| DLC 缺少主課的檢查點導覽、真實勾選數與主持操作摘要 | 兩版共同行為對齊，保留獨立儲存前綴、匯出檔名、時間軸與返回任務表 | `test_shared_behavior_stays_in_sync`、兩版逐頁走查 |
| 一般下一頁經過特殊流程，復原後容易接錯段落 | 一般流程略過復原包；主課例外卡回原 Gate，DLC 五個復原包回對應接續任務 | `test_dlc_recovery_routes_and_independent_codes`、`test_primary_route_and_checklist_scope` |
| 表單修改後立刻離開可能漏存最後一次決定 | 每次變更立即保存，保留未選擇狀態與清除確認 | `test_decision_is_saved_before_leaving`：先重現漏存，再確認修正；另測清除與儲存失敗 |
| Enter 搜尋後命中的摺疊內容仍關著；首次向上選擇會跳過末項 | 滑鼠與鍵盤共用開啟結果的流程；修正選擇索引及輔助閱讀狀態 | `test_keyboard_search_opens_fold_and_selects_last_result`：先重現，再確認修正 |
| 關閉的手機導覽仍可取得鍵盤焦點 | 關閉時停用畫面外連結，開啟時停用背景，關閉後還原焦點；跨桌面／手機尺寸同步 | `test_closed_mobile_navigation_is_not_focusable`、320／390／768／1440px 走查 |
| 檢查點與任務卡分開，判斷時得離開目前操作位置 | 就地展開原有說明與任務卡，不複製內容或新增判斷欄位；底部按鈕返回目前檢查點 | `test_reference_can_be_read_without_leaving_checkpoint`、主課 B2 與 DLC D3a 畫面 |
| 進檢查點後，段落開頭的最低完成線與復原提示也被藏起來 | 時間不夠、縮短版及看投影等必要提醒保持直接可見，任務卡才使用就地展開 | 同上測試；緊急提示不在摺疊區內 |
| Gate 1 記錄決策時離開目前檢查點，下一步可能跳過 Gate 2 | 決策表可在頁尾就地展開，較早檢查點開啟表單連結時保留原位置，填完返回原檢查點 | `test_early_gate_decision_keeps_the_next_gate`：先重現，再確認 Gate 2 仍是下一步；欄位與選項未改 |
| 從 D2 檢查點 1 開始時看不到兩個對話的準備說明 | 第一個檢查點直接展開既有的開始前說明 | `test_reference_can_be_read_without_leaving_checkpoint` 的 D2 分支；提示詞內容、角色與權限規則未改 |
| DLC 六個檢查點的卡片在手機佔去大半畫面 | 手機顯示編號與時間，完整名稱保留在內文及輔助閱讀標籤 | 390px D1 畫面；所有頁面的窄螢幕溢出檢查 |
| 主持人容易混淆全場碼與私下復原碼，便利貼可能保留上一輪狀態 | 明確標出解鎖碼受眾；兩版開場一致說明換檢查點先收起便利貼、成功免重貼檢查提示詞 | 兩版全部講者頁；開場文字／投影對照 |

## 驗證範圍

- 一般流程逐一經過兩版所有頁面、檢查點、決策與反思區；分別測試特殊流程的入口與返回。
- 對可見提示詞的複製內容、Windows／macOS 分頁、每張表單、單份 Markdown／全部 ZIP 匯出與重新開啟的保存值做檢查。
- 從瀏覽器實際下載的學員包與目前受控候選包比對 SHA256；一般解鎖碼不能開啟復原頁。
- 在 320、390、768、1440px 查看兩版所有頁面；檢查淺色、深色及需求卡、搭檔準備等代表畫面。
- 在 1400×850、1280×720 檢查主課 63 張與 DLC 71 張講者頁，確認操作摘要、角色與解鎖碼受眾，並確認計時與導航控制不溢出。
- 重新跑課程一致性、來源隔離、用詞、四塊檢查點、簡報／Runbook 對照、排版與完整教材發布檢查。

瀏覽器情境紀錄與下載測試檔放在作者本機 `.codex-tmp/ux-full/`。情境中的表單內容是測試資料，不是學員實作成果。保存值依鍵和值比對，不依賴瀏覽器未保證的 localStorage 列舉順序。
